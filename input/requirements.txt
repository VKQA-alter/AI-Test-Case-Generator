User Story: All Leads Page in Brand Owner Profile

As a Brand Owner or Admin
I want to access an All Leads page within a Brand Owner’s profile
So that I can view, search, filter, download, and manage all leads associated with that Brand Owner’s brands.

Description:

The All Leads page will be available within the Brand Owner (BO) profile and will provide a consolidated view of all leads associated with the brands handled by that profile. Users should be able to categorize leads by brand status, filter and search leads, view lead details, and perform lead-related actions.

Acceptance Criteria:

Access Control

The All Leads page should be accessible only to BO and Admin roles.

Brand Status Dropdown

A dropdown should be available to categorize leads by brand status:

Active Brands

Offloaded Brands

Removed Brands

Default selection should be Active Brands.

Selecting an option should update the leads displayed in the table.

Search Functionality

Users should be able to search leads using a search field.

Search should support:

Brand

Event Name

Inventory Name

Search results should update the table accordingly.

Download Option

Users should be able to download the leads data from the page.

The downloaded data should reflect the leads currently displayed based on applied filters or selections.

Filters

Users should be able to filter leads using a filter panel containing:

Regions & Cities

Industries

Company Name

Agency

Verticals

Previously Closed Deals

Annual Revenue

Assigned By

Brand Engagement

Applying filters should update the leads table.

Lead Stage Tabs

The page should contain stage-based tabs for lead categorization:

All

Assigned

In Progress

Won

Not Interested

Selecting a tab should filter leads based on the selected stage.

Leads Table (Active & Offloaded Brands)

For Active Brands and Offloaded Brands, the table should display the following columns:

Brand

Event Name

Inventory Name

Stage

Assigned On

Assigned By

Last Updated On

Recently Contacted POC

Recent Note Added

Recent Note Timestamp

Collaborators

Last Contacted

Project Owners

Leads Table (Removed Brands)

For Removed Brands, the table should display the following columns:

Brand

Event Name

Inventory Name

Stage

Assigned On

Assigned By

Collaborators

Last Contacted

Project Owners

Lead Row Actions

Each row in the leads table should contain a more options menu allowing the user to perform the following actions:

Lead Info

Update Stage

Update All Leads Stage

Add Task

Open Event Chat

View Deck

View Event Info

View Inventory Info

View Project Owners

Add Collaborator
